# Registros TSPi

Formularios del **TSPi Workbook (versión 20041202)** que el equipo mantiene semana a semana. Responsable de consolidarlos: **Gerente de planeación** (`[PLANEACION]`), cada domingo antes de la reunión de seguimiento.

| Archivo | Formulario TSPi | Contenido |
|---|---|---|
| `TASK-plan.csv` | TASK / SCHEDULE | Tareas T01–T32 con horas planeadas, semana y dependencias (plan v1.0). |
| `LOGT.csv` | LOGT – registro de tiempos | Cada sesión de trabajo: fecha, inicio, fin, interrupciones, tiempo delta (min), tarea, rol y fase. |
| `LOGD.csv` | LOGD – registro de defectos | Cada defecto: tarea, tipo, fase en que se inyectó, fase en que se removió y tiempo de corrección. |

Se registra **tiempo en tarea**: el tiempo transcurrido menos las interrupciones, medido en minutos.
